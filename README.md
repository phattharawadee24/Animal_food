## 📌 บทนำ (Overview)

> [!NOTE]
> **PAW LABZ** พัฒนาขึ้นเพื่อแก้ปัญหาสินค้าขาดสต็อกหน้าร้าน และลดขั้นตอนความล่าช้าในการทำเรื่องขอเบิกของระหว่าง **คลังสินค้าส่วนกลาง (HQ)** กับ **หน้าร้านสาขา (สยาม, อารีย์, บางนา)**

หน้าเว็บออกแบบในสไตล์ **Neo-brutalism + Bento Grid** ที่ทันสมัย สบายตา สีสันสดใส มีลูกเล่นเอฟเฟกต์ Pop-up และ Confetti ในตัว โดยเขียนด้วย **Vanilla Web Technologies (HTML, CSS, JS)** 100% จึงทำงานได้เร็วมาก โหลดปุ๊บติดปั๊บ และไม่ต้องลงโปรแกรมหรือไลบรารีเสริมใดๆ

---

## ✨ จุดเด่นของระบบ (Key Features)

```
[ สาขาส่งใบเบิก 🛒 ] ───▶ [ คลังกลางตรวจสอบ 👀 ] ───▶ [ กดอนุมัติ ✅ ] ───▶ [ ตัดสต็อก & โอนเข้าสาขาทันที 🚀 ]
```

* 🎭 **จำลองสลับบทบาท (Role / POV Switcher):** สลับมุมมองได้ทันทีระหว่าง `👑 คลังกลาง (HQ)` หรือหน้าร้านสาขาต่างๆ (`🏪 สยาม`, `🏪 อารีย์`, `🏪 บางนา`)
* 📊 **แดชบอร์ดสถิติ Bento Grid:** สรุปยอดสต็อกรวม, จำนวน SKU ทั้งหมด, สินค้าที่ใกล้หมดต้องรีบเติม และจำนวนใบเบิกที่รอการพิจารณา
* 📦 **ระบบจัดการสต็อกพร้อมแถบพลัง:** แสดงระดับสินค้าคงเหลือด้วยแถบเปอร์เซ็นต์สีเขียว/แดง และเตือนทันทีเมื่อสินค้าต่ำกว่าระดับปลอดภัย (Safety Stock)
* 📡 **เรดาร์ส่องสต็อกทุกสาขา (All-Branch Radar):** ดูภาพรวมสินค้าทุกรายการในทุกสาขาเทียบกันแบบเรียลไทม์ในหน้าเดียว
* 🛒 **เบิกสินค้าอัจฉริยะ (Smart Requisition):** มีปุ่ม `⚡ เติมของใกล้หมดให้อัตโนมัติ` ช่วยคำนวณและดึงสินค้าที่ใกล้ขาดเชลฟ์เข้าตะกร้าให้ทันที
* ✅ **พิจารณาอนุมัติและตัดสต็อกอัตโนมัติ:** คลังกลางสามารถตรวจสอบยอดที่มีจริง ปรับลดจำนวน หรือปัดตกใบเบิกได้ เมื่ออนุมัติแล้วระบบจะตัดสต็อกคลังกลางและเพิ่มเข้าสาขาให้อัตโนมัติ
* 📥 **รับสินค้าเข้าคลังกลาง (HQ Restock):** บันทึกการรับสินค้าล็อตใหม่จากโรงงานเข้าสู่คลังกลางได้ตลอดเวลา
* 📜 **ไทม์ไลน์บันทึกประวัติ (Activity Timeline):** บันทึกทุกความเคลื่อนไหว (เวลา, ผู้ทำรายการ, รายละเอียด) อย่างโปร่งใส ตรวจสอบย้อนหลังได้
* 🎨 **สลับธีมสีได้ 3 มู้ด:** `✨ Y2K Pop`, `🎀 Coquette`, และ `👾 Cyber Neon` บันทึกค่าไว้ในเครื่องอัตโนมัติ

## 🛠️ เทคโนโลยีและเครื่องมือ (Tech Stack)

### 1. ภาษาและเทคโนโลยีหลัก
* **HTML5:** โครงสร้างเว็บมาตรฐานแบบ Semantic Markup (`<aside>`, `<main>`, `<nav>`, `<table>`)
* **CSS3:** 
  * ใช้ **CSS Custom Properties (Variables)** จัดการชุดสีและระบบเปลี่ยนธีม
  * จัดเลย์เอาต์ด้วย **Flexbox** และ **CSS Grid**
  * ลูกเล่นแอนิเมชัน **CSS Keyframes** (Pop-up Modal, Confetti physics)
  * รองรับ **Responsive Design** ใช้งานได้ทั้งบนคอมพิวเตอร์และมือถือ
* **JavaScript (Vanilla JS ES6+):** 
  * ไม่พึ่งพาเฟรมเวิร์กขนาดใหญ่ภายนอก (Zero Dependencies) โค้ดเบา โหลดเร็ว
  * ควบคุมการแสดงผลหน้าจอแบบ **Single Page Application (SPA)**
  * มีระบบคำนวณและตัดยอดสต็อกอัตโนมัติ
  * จัดการความปลอดภัย ป้องกันช่องโหว่ XSS (HTML Escaping)
* **Web Storage API (`localStorage`):** 
  * บันทึกข้อมูลสต็อก สถานะใบเบิก และประวัติลงบนเครื่อง ข้อมูลไม่หายเมื่อรีเฟรชหน้าเว็บ

### 2. โปรแกรมที่ใช้พัฒนา
* **Visual Studio Code (VS Code) / Antigravity IDE**
* **Google Chrome / Microsoft Edge** (ทดสอบการทำงานและดีบักผ่าน DevTools F12)
* **Google Fonts API:** ฟอนต์ภาษาไทย `Prompt` และ `Noto Sans Thai`

## 🚀 วิธีเปิดใช้งานระบบ (How to Run)

เลือกเปิดใช้งานได้ตามความสะดวก:

### 🟢 วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์ (ง่ายที่สุด)
1. เข้าไปที่โฟลเดอร์ `d:\งาน\Animal_food`
2. ดับเบิลคลิกที่ไฟล์ **`Animal_food.html`** หน้าเว็บจะเปิดบนเบราว์เซอร์พร้อมใช้งานทันที

---

### 🟡 วิธีที่ 2: รันด้วยคำสั่ง Python (แนะนำสำหรับการทดสอบ)
เปิด **Terminal / PowerShell** แล้วพิมพ์คำสั่ง:
```bash
cd "d:\งาน\Animal_food"
python -m http.server 8000
```
เปิดเบราว์เซอร์ไปที่: **`http://localhost:8000/Animal_food.html`**

---

### 🔵 วิธีที่ 3: รันด้วย Node.js
```bash
cd "d:\งาน\Animal_food"
npx serve .
```

---

### 🟣 วิธีที่ 4: เปิดด้วย VS Code Live Server
* เปิดโฟลเดอร์ใน **VS Code** คลิกขวาที่ไฟล์ `Animal_food.html` แล้วเลือก **"Open with Live Server"**

## 🧪 ขั้นตอนทดลองใช้งานระบบ (Simulation Guide)

> [!TIP]
> ลองทำตาม 5 ขั้นตอนนี้ เพื่อดูการทำงานตั้งแต่ต้นจนจบ:

1. **สวมบทบาทเป็นสาขา:**  
   ไปที่เมนูด้านซ้าย ในช่อง **"🎭 สวมบทบาทเป็น (POV)"** เลือกเป็น `🏪 สาขา 2 (อารีย์)`
2. **สร้างใบเบิกสินค้า:**  
   คลิกเมนู **"🛒 สร้างใบเบิกสินค้า"** แล้วกดปุ่ม `⚡ เติมของใกล้หมดให้อัตโนมัติ` ระบบจะคำนวณจำนวนที่ควรเติมให้ทันที จากนั้นกด **"🚀 ส่งใบเบิกให้คลังกลาง"**
3. **สลับไปเป็นคลังกลาง:**  
   สลับช่อง POV กลับมาเป็น `👑 คลังกลาง (HQ) [ผู้อนุมัติ]` จะสังเกตเห็นตัวเลขแจ้งเตือนสีเขียวที่เมนู **"💌 คำขอเบิกเข้า"**
4. **พิจารณาอนุมัติ:**  
   กดปุ่ม `⚡ พิจารณาอนุมัติ` ตรวจสอบยอด แล้วกด **"✅ อนุมัติ & ตัดสต็อกเลย!"** ระบบจะปล่อยเอฟเฟกต์ Confetti ฉลอง และตัดสต็อกคลังกลางโอนเข้าสาขาให้อัตโนมัติ
5. **ตรวจสอบผลลัพธ์:**  
   เข้าไปดูที่เมนู **"📦 คลังสินค้า (HQ)"** และ **"📜 ไทม์ไลน์ประวัติ"** เพื่อดูบันทึกการตัดสต็อกย้อนหลัง
