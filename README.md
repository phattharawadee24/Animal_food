## 📌 เกี่ยวกับโปรเจกต์ (Overview)
**PAW LABZ INVENTORY OS** เป็นเว็บแอปพลิเคชันที่สร้างขึ้นเพื่อจำลองและจัดการระบบคลังสินค้าอาหารสัตว์และอุปกรณ์สัตว์เลี้ยง สำหรับธุรกิจที่มี **คลังสินค้าส่วนกลาง (Headquarters - HQ)** และ **ร้านค้าปลีกหลายสาขา (Branches: สยาม, อารีย์, บางนา)** 

ระบบสามารถจำลองบทบาทผู้ใช้งาน (POV Simulation) ให้เห็นกระบวนการทำงานจริง ตั้งแต่:
1. สาขาตรวจสอบระดับสต็อกสินค้าหน้าร้าน
2. ส่งใบเบิกสินค้า (Requisition) พร้อมระบบเติมสินค้าใกล้หมดลงตะกร้าอัตโนมัติ
3. คลังกลางตรวจสอบสต็อกคงเหลือ พิจารณาอนุมัติหรือปรับลดยอด
4. ระบบทำการ **ตัดสต็อกคลังกลางและเพิ่มเข้าสต็อกสาขาให้อัตโนมัติทันที** พร้อมบันทึกประวัติการทำรายการย้อนหลัง

## 💻 เทคโนโลยีที่ใช้พัฒนา (Technology Stack)

โปรเจกต์นี้ตั้งใจพัฒนาด้วย **Pure Vanilla Web Architecture** เพื่อให้เข้าใจโครงสร้างพื้นฐานของการเขียนเว็บอย่างแท้จริง โค้ดสะอาด โหลดได้รวดเร็ว และไม่ต้องติดตั้งแพ็กเกจภายนอกให้ซับซ้อน:

| หมวดหมู่ | เทคโนโลยีที่ใช้ | รายละเอียดการนำมาใช้งาน |
| :--- | :--- | :--- |
| **โครงสร้างเว็บ (Markup)** | **HTML5** | ใช้โครงสร้างแบบ Semantic Markup (`<aside>`, `<main>`, `<nav>`, `<table>`) รองรับการแสดงผลมาตรฐานสากล |
| **การตกแต่งและจัดวาง (Styling)** | **CSS3 (Modern CSS)** | - **CSS Custom Properties (Variables):** สำหรับจัดการชุดสีและสลับธีม 3 รูปแบบ (Y2K Pop, Coquette, Cyber Neon)<br>- **CSS Grid & Flexbox:** จัดเลย์เอาต์แดชบอร์ดแบบ Bento Grid สวยงาม<br>- **CSS Keyframe Animations:** เอฟเฟกต์ Pop Modal, Hover Animation, และ Confetti Physics<br>- **Media Queries:** รองรับการแสดงผล Responsive ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ |
| **ตรรกะและการประมวลผล (Scripting)** | **JavaScript (ES6+)** | - **Data Modeling:** โครงสร้างข้อมูลจำลองแบบ Object Array สำหรับสินค้า ใบเบิก และประวัติการทำงาน<br>- **DOM Manipulation:** วาดหน้าจอ (Render) แบบ Single-Page Application (SPA) น้ำหนักเบา<br>- **Business Logic:** ระบบคำนวณและตัดสต็อกสินค้าอัตโนมัติเมื่ออนุมัติใบเบิก<br>- **Security:** ฟังก์ชัน Escape HTML เพื่อป้องกันช่องโหว่ XSS (Cross-Site Scripting) |
| **ระบบฐานข้อมูลจำลอง (Storage)** | **Web Storage API (`localStorage`)** | จัดเก็บข้อมูลสต็อกและสถานะใบเบิกลงบนเบราว์เซอร์ของผู้ใช้ ข้อมูลไม่หายเมื่อรีเฟรชหน้าเว็บ พร้อมมีปุ่มคืนค่าเริ่มต้น (Reset Data) |
| **ฟอนต์และไอคอน (Typography & Assets)** | **Google Fonts & Unicode Emojis** | ใช้ฟอนต์ภาษาไทย **`Prompt`** และ **`Noto Sans Thai`** สบายตา อ่านง่าย ใช้ Native Emojis ช่วยสื่อความหมายโดยไม่ต้องโหลดไฟล์ภาพภายนอก |

## 🛠️ โปรแกรมและเครื่องมือที่ใช้ทำงาน (Development Tools)

1. **Visual Studio Code (VS Code) / Antigravity IDE:**
   - โปรแกรม Code Editor หลักที่ใช้เขียนโค้ด HTML, CSS, JavaScript และ Markdown
   - ใช้ Extension ช่วยอำนวยความสะดวก เช่น *Live Server*, *Prettier*, *Color Highlight*
2. **Web Browsers (Google Chrome / Microsoft Edge):**
   - ใช้สำหรับรันและทดสอบการแสดงผลหน้าเว็บ

   - ใช้สำหรับเปิด Local HTTP Server จำลองโฮสต์ในการทดสอบระบบ

## 🤖 เอไอ (AI) ที่นำมาเป็นตัวช่วยทำงาน (AI Assistance)

ในการพัฒนาโปรเจกต์นี้ ได้นำเทคโนโลยีปัญญาประดิษฐ์ **Google Gemini (ผ่านระบบผู้ช่วย Antigravity โดย Google DeepMind)** เข้ามาเป็นผู้ช่วยในการทำงานในขั้นตอนสำคัญดังนี้:

1. **ช่วยออกแบบสถาปัตยกรรมระบบ (System & Workflow Architecture):**
   - ช่วยวางผังการไหลของข้อมูล (Data Flow) ระหว่างคลังกลางและสาขา เพื่อให้เกิดกระบวนการขอเบิก-อนุมัติ-ตัดสต็อกที่สมบูรณ์และถูกต้องตามหลักการจัดการคลังสินค้าจริง
2. **ช่วยสร้างสรรค์แนวคิด UI/UX (Design Ideation):**
   - แนะนำการออกแบบในสไตล์ **Neo-brutalism** ที่มีเส้นขอบชัดเจน สีสันสดใส ผสานกับ **Bento Grid** ทำให้หน้าแดชบอร์ดดูมีระดับ เข้าถึงง่าย และนำเสนอธีมสีได้ถึง 3 รูปแบบ
3. **จัดระเบียบโค้ดให้สะอาดตามฉบับนักเรียน/นักศึกษา (Code Formatting & Clean Refactoring):**
   - จัดย่อหน้า (Indentation) ให้อ่านง่าย มีระเบียบ
   - เปลี่ยนชื่อตัวแปรที่เข้าใจยากให้สื่อความหมายชัดเจน (Descriptive Naming)
   - เพิ่มคำอธิบายภาษาไทย (Thai Comments) ครอบคลุมทุกโมดูล ทำให้ผู้เรียนสามารถนำโค้ดไปศึกษาต่อหรือนำเสนออาจารย์ได้อย่างมั่นใจ
4. **ตรวจสอบและดักจับข้อผิดพลาด (Bug Fixing & Error Prevention):**
   - ตรวจสอบชนิดข้อมูล (Data Type Parsing) ป้องกันปัญหาค่าที่เป็น `NaN` หรือตัวเลขติดลบ
   - ตรวจสอบสต็อกคลังกลางไม่ให้จ่ายของเกินจำนวนที่มีอยู่จริง
   - ตรวจทานโครงสร้าง JavaScript Syntax ให้ถูกต้อง 100% ปราศจาก Error บน Console
5. **ช่วยจัดทำเอกสารและคู่มือ (Documentation):**
   - รวบรวมข้อมูลและจัดทำไฟล์ `README.md` ฉบับสมบูรณ์นี้

## ✨ ฟังก์ชันเด่นของระบบ (Core Features)

- 🎭 **Role / POV Switcher:** สามารถสลับมุมมองผู้ใช้ได้ทันทีระหว่าง `👑 คลังกลาง (HQ)` หรือ `🏪 สาขา 1 (สยาม)`, `🏪 สาขา 2 (อารีย์)`, `🏪 สาขา 3 (บางนา)`
- 🌈 **Bento Dashboard:** การ์ดสถิติแสดงสต็อกรวม, จำนวน SKU ทั้งหมด, สินค้าที่ต้องสั่งเพิ่มด่วน และใบเบิกที่รออนุมัติ
- 📦 **Stock Management & Visual Bar:** แสดงรายการสินค้าพร้อมแถบหลอดระดับสต็อก และป้ายเตือนสถานะเมื่อสินค้าต่ำกว่าเกณฑ์ขั้นต่ำ (Safety Stock)
- 🔥 **All-Branch Radar:** ตารางแสดงสต็อกเปรียบเทียบทุกสาขาพร้อมยอดรวมในหน้าเดียว ไฮไลต์ตัวเลขสีแดงเมื่อสาขาใดสต็อกใกล้หมด
- 🛒 **Smart Requisition:** สาขาสามารถกดปุ่ม `⚡ เติมของใกล้หมดให้อัตโนมัติ` เพื่อดึงสินค้าที่ขาดเข้าตะกร้าเบิกโดยไม่ต้องคำนวณเอง
- ✅ **Approval & Auto Stock Transfer:** คลังกลางสามารถเคาะอนุมัติ ปรับลดยอดตามสต็อกที่มีจริง หรือปัดตกใบเบิก เมื่ออนุมัติแล้วระบบจะตัดสต็อก HQ และโอนเข้าสาขาปลายทางทันที
- ➕ **Receive Stock (HQ):** คลังกลางสามารถกดรับสินค้าใหม่จากโรงงานเข้าสู่คลังได้ตลอดเวลา
- 📜 **Activity Timeline Log:** บันทึกประวัติทุกความเคลื่อนไหว (ใครเบิก, ใครอนุมัติ, วันเวลาใด) สามารถตรวจสอบย้อนหลังได้
- 🎨 **Multi-Theme Vibes:** รองรับ 3 ธีมสีสดใส ได้แก่ `✨ Y2K Pop`, `🎀 Coquette`, และ `👾 Cyber Neon` บันทึกธีมที่เลือกไว้ในเครื่องอัตโนมัติ

## 🚀 คำสั่งและวิธีเปิดใช้งานระบบ (How to Run)

คุณสามารถเลือกเปิดใช้งานระบบได้หลากหลายวิธีตามความสะดวก ดังนี้:

### วิธีที่ 1: ดับเบิลคลิกเปิดไฟล์โดยตรง (ง่ายที่สุด - ไม่ต้องติดตั้งโปรแกรมเสริม)
1. ไปที่โฟลเดอร์ `d:\งาน\Animal_food`
2. ดับเบิลคลิกที่ไฟล์ **`Animal_food.html`**
3. ไฟล์จะเปิดขึ้นบนเว็บเบราว์เซอร์เริ่มต้นของคุณ (เช่น Google Chrome หรือ Microsoft Edge) และพร้อมใช้งานได้ทันที

---

### วิธีที่ 2: รันผ่านคำสั่ง Python HTTP Server (แนะนำสำหรับการทดสอบ)
เปิด **PowerShell** หรือ **Command Prompt** แล้วรันคำสั่งดังนี้:

```powershell
# 1. ย้ายเข้าไปที่โฟลเดอร์โปรเจกต์
cd "d:\งาน\Animal_food"

# 2. รันคำสั่งเปิด Local Server ด้วย Python
python -m http.server 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่ลิงก์:  
👉 **`http://localhost:8000/Animal_food.html`**

*(เมื่อต้องการหยุดการทำงาน ให้กด `Ctrl + C` ในหน้าต่าง Terminal)*

---

### วิธีที่ 3: รันผ่านคำสั่ง Node.js (npx serve)
หากเครื่องของคุณติดตั้ง Node.js สามารถรันคำสั่งดังนี้:

```powershell
cd "d:\งาน\Animal_food"
npx serve .
```
จากนั้นเปิดเบราว์เซอร์ไปที่ลิงก์ URL ที่แสดงบนหน้าจอ (เช่น `http://localhost:3000/Animal_food.html`)

---

### วิธีที่ 4: รันผ่านส่วนขยาย VS Code "Live Server"
1. เปิดโฟลเดอร์ `d:\งาน\Animal_food` ในโปรแกรม **VS Code**
2. คลิกขวาที่ไฟล์ `Animal_food.html`
3. เลือก **"Open with Live Server"** หน้าต่างเบราว์เซอร์จะเปิดขึ้นมาอัตโนมัติ

## 🧪 ขั้นตอนทดลองใช้งานระบบ (Step-by-Step Simulation Guide)

เพื่อทดสอบการทำงานของระบบให้ครบทุกฟังก์ชัน แนะนำให้ลองทำตามขั้นตอนนี้:

1. **เข้าสู่ระบบในมุมมองสาขา:**
   - ที่แถบเมนูด้านซ้าย ในช่อง **"🎭 สวมบทบาทเป็น (POV)"** ให้เลือกเป็น `🏪 สาขา 2 (อารีย์)`
2. **สร้างใบเบิกสินค้า:**
   - คลิกเมนู **"🛒 สร้างใบเบิกสินค้า"**
   - ทดลองกดปุ่ม **"⚡ เติมของใกล้หมดให้อัตโนมัติ"** สังเกตว่าระบบจะคำนวณสินค้าที่ใกล้หมดใส่จำนวนให้ทันที
   - หรือจะพิมพ์ตัวเลขจำนวนที่ต้องการเบิกด้วยตนเองในช่องสินค้าต่างๆ
   - กดปุ่ม **"🚀 ส่งใบเบิกให้คลังกลาง"** พิมพ์ข้อความบันทึก เช่น *"ขอเติมด่วนครับ"* แล้วกดยืนยัน
3. **สลับไปมุมมองคลังกลางเพื่อพิจารณา:**
   - สลับช่อง POV กลับมาเป็น `👑 คลังกลาง (HQ) [ผู้อนุมัติ]`
   - สังเกตว่าที่เมนู **"💌 คำขอเบิกเข้า"** จะมีป้ายแจ้งเตือนสีเขียวขึ้นมาว่ามีใบเบิกค้างอยู่
   - คลิกเข้าไปดูรายการ และกดปุ่ม **"⚡ พิจารณาอนุมัติ"**
4. **อนุมัติและดูผลการตัดสต็อก:**
   - ตรวจสอบจำนวนสินค้าที่คลังกลางมีจริง จากนั้นกดปุ่ม **"✅ อนุมัติ & ตัดสต็อกเลย!"**
   - จะมีเอฟเฟกต์ Confetti แสดงความยินดี
   - คลิกไปที่เมนู **"📦 คลังสินค้า (HQ)"** จะพบว่าสต็อกคลังกลางถูกหักออกไป
   - เมื่อสลับ POV กลับไปดูที่ `🏪 สาขา 2 (อารีย์)` จะพบว่าสต็อกในสาขาเพิ่มขึ้นทันที!
5. **ส่องประวัติย้อนหลัง:**
   - คลิกเมนู **"📜 ไทม์ไลน์ประวัติ"** เพื่อดู Log บันทึกทุกความเคลื่อนไหวพร้อมวันเวลาอย่างโปร่งใส
